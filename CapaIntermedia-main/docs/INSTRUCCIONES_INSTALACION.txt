💡 CÓMO USAR EN CÓDIGO EXISTENTE (Ejemplos)
══════════════════════════════════════════════════════════════════

Puedes simplificar queries existentes con las nuevas vistas:

Ejemplo 1 - Comentarios de publicación:
----------------------------------------
ANTES:
  SELECT c.*, u.Nombre, u.Foto 
  FROM comentario c 
  INNER JOIN usuario u ON c.ID_User = u.ID_User 
  WHERE c.ID_Publi = ?

AHORA:
  SELECT * FROM V_ComentariosPublicacion WHERE ID_Publi = ?

Ejemplo 2 - Publicaciones con detalles:
----------------------------------------
ANTES:
  SELECT p.*, c.Nombre AS Cat, m.Nombre AS Mund, u.Nombre AS User
  FROM publicacion p
  INNER JOIN categoria c ON p.ID_Categ = c.ID_Categ
  INNER JOIN mundial m ON p.ID_Mundial = m.ID_Mundial
  INNER JOIN usuario u ON p.ID_User = u.ID_User
  WHERE p.Estatus = 2

AHORA:
  SELECT * FROM V_PublicacionesConDetalles WHERE Estatus = 2

Ejemplo 3 - Edad de usuario:
----------------------------------------
ANTES:
  Calcular edad en PHP con DateTime

AHORA:
  SELECT FN_CalcularEdadUsuario(15) AS Edad

══════════════════════════════════════════════════════════════════
💡 INTEGRACIÓN EN PHP
══════════════════════════════════════════════════════════════════

Todos los elementos SQL están integrados en PHP:

UserRepository:
  - getUserStatistics($userId)        → V_EstadisticasPublicaciones
  - getActiveUsers($limit)            → V_UsuariosActivos
  - getUserAge($userId)               → FN_CalcularEdadUsuario

PublicationRepository:
  - getPopularPublications($limit)    → V_PublicacionesPopulares
  - getApprovedComments($pubId)       → V_ComentariosAprobados
  - getPublicationReactionCount(...)  → FN_ContarReaccionesPublicacion

Triggers:
  - Se ejecutan automáticamente en INSERT/UPDATE
  - No requieren llamadas explícitas desde PHP
